The state of the art in distributed symmetry breaking

Known upper bounds for the four classical symmetry-breaking problems in distributed graph algorithms, with the state of the art highlighted for every range of the maximum degree.

Maximal matching A set of disjoint edges that cannot be extended. Maximal independent set A set of pairwise non-adjacent nodes that cannot be extended. Vertex coloring Colors for the nodes so that adjacent nodes differ. Edge coloring Colors for the edges so that adjacent edges differ. Network decomposition Low-diameter clusters, colored so that adjacent clusters differ.
